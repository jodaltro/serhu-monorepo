## 🔍 O Que Muda?

| Elemento | EN | PT | ES | FR |
|----------|----|----|----|----|
| `language=` | `"en"` | `"pt"` | `"es"` | `"fr"` |
| Erikson | You are navigating | Você está navegando | Estás navegando | Vous naviguez |
| Capabilities | React to immediate | Reagir a estímulos | Reaccionar a estímulos | Réagir aux stimuli |
| Limitations | Use symbols | Usar símbolos | Usar símbolos | Utiliser des symboles |
| Language Style | Very simple, short | Muito simples, frases | Muy simple, frases | Très simple, phrases |

## ⚙️ Como Funciona

### 1. Na Criação
```python
orch = Orchestrator(
    being_name="Stella",
    language="pt",  # ← Você escolhe
    ...
)
```

### 2. Na Geração do Prompt
```python

    caps = get_stage_capabilities(language, stage)

    erikson_desc = get_erikson_description(language, conflict)

    # Essas strings traduzidas são inseridas no XML
```

### 3. No Armazenamento
O campo `language` é persistido no Supabase:
```sql
SELECT being_id, name, language, state 
FROM personality_ledger
WHERE being_id = '...'

-- Resultado:
-- | abc123... | Estrela | pt | {...} |
```

### 4. No Carregamento
```python
orch = Orchestrator(being_id="abc123...")
# Supabase retorna language="pt"
# Todos os prompts são gerados em português
```

## 🎯 Benefícios

✅ **Imersão**: Ser "fala" no idioma do usuário  
✅ **Coerência**: Tudo (prompt, memória, output) no mesmo idioma  
✅ **Escalabilidade**: Suporta múltiplos idiomas sem código duplicado  
✅ **Manutenibilidade**: Traduções centralizadas em `i18n.py`  
✅ **Testabilidade**: 10 testes validam cada idioma  

---

## 📝 Notas

- Os scores de personalidade (HEXACO, TCI, etc.) são **iguais** em todos os idiomas
- Apenas o **texto de instrução** muda
- O LLM receberá instruções no idioma correto do Ser
- Se o Ser é criado em português, os prompts do LLM serão em português
